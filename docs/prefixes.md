# Prefixes in Persona 3 FES

These prefixes come from the game's credits and are used to attribute source files to their
original developers.

## Developer prefixes

| Prefix | Developer name | File name examples | Role |
| --- | --- | --- | --- |
| `k_` | Yujiro Kosaka | `k_dungeon.c`, `k_fldCamera.c` | Field developer |
| `mt` | Masaya Takano | `mt_EvtMain.c`, `mt_EvtMenu.c` | Event developer |
| `h_` | Hirokazu Tohyama | `h_sfdPlay.c`, `h_malloc.c` | Chief developer |
| `nm` | Nobuyoshi Miwa | `nmSequence.c`, `nmCmdList.c` | Facility developer |
| `d_` | Daisuke Yajima | `d_sysm.c`, `d_sysmdrw.c` | Field sub-developer |
| `y_` | Yukinobu Miyashita | `y_stparts.c` | Interface sub-developer |

| `sfl_` | Shuffle | `sfl_card.c`, `sfl_result.c` |

| `bp_` | Battle panel | `bp_dialog.c`, `bp_persona.c` |
